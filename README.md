# HoldStack

AI 와 대화하다 보면 답변 하나에서 의문이 여러 개 생긴다. 한꺼번에 물으면 대화가 어지러워지고, 하나만 물으면 나머지를 잊는다. HoldStack 은 그 의문들을 잠시 옆에 보관해 두고 하나씩 꺼내 묻게 해 주는 macOS 메뉴 막대 앱이다. 테트리스의 홀드에서 따온 개념이지만 여러 개를 쌓을 수 있어서, 마지막에 넣은 것이 먼저 나오는 스택(stack)으로 동작한다.

클립보드 관리자처럼 전역으로 돌기 때문에 터미널에서도, 브라우저에서도, Claude Code 창에서도 똑같이 쓴다.

## 사용법

| 기본 단축키 | 하는 일 |
|---|---|
| `⌃⇧H` | 선택한 문장을 붙잡고, 그 문장에 대한 의문을 적는 창을 연다. 선택이 없으면 의문만 적는다 |
| `⌃⇧L` | 목록 창을 열고 닫는다 |
| `⌃⇧P` | 맨 위 의문을 지금 입력하던 곳에 붙여넣고 스택에서 뺀다 |

`⌃⇧H` 로 연 창에서는 위에 붙잡은 문장이 보이고, 아래 칸에 질문을 적어 Enter 를 누르면 둘이 한 항목으로 쌓이고 창이 닫힌다. 질문을 비운 채 Enter 를 누르면 문장만 보관된다. `esc` 는 보관하지 않고 닫는다.

`⌃⇧L` 목록에서는 항목마다 붙잡은 문장이 윗줄에 흐리게, 나의 질문이 그 아래에 보인다. 목록 창의 입력칸에 새 의문을 적고 Enter 를 눌러도 쌓이고, 입력칸이 비어 있을 때는 키가 목록에 작용한다.

불러오면 이런 모양으로 붙여넣어진다. 문장이 없으면 질문만, 질문이 없으면 따옴표 친 문장만 들어간다.

```
"붙잡은 문장"

나의 질문
```

| 목록 창 안의 키 | 하는 일 |
|---|---|
| `↑` `↓` | 항목 사이를 이동한다 |
| `⏎` | 고른 항목을 원래 앱에 붙여넣고 스택에서 뺀다 |
| `⌫` | 고른 항목을 지운다 |
| `⌘Z` | 방금 불러오거나 지운 것을 한 번 되돌린다 |
| `esc` | 창을 닫는다 |

전역 단축키 세 개는 메뉴 막대 아이콘의 「설정…」(`⌘,`)에서 바꾼다. 버튼을 누르고 새 조합을 누르면 바뀌고, `esc` 를 누르면 취소된다. 조합에는 `⌃` 나 `⌥`, `⌘` 중 하나가 들어가야 한다. 모든 앱이 쓰는 `⌘C` 나 `⌘V` 같은 편집 단축키는 고를 수 없고, 다른 동작이나 다른 앱이 이미 쓰는 조합은 안내 문구와 함께 거부된다. 목록 창 안의 키는 고정이다. 같은 설정 창에서 목록 창의 투명도를 30% 에서 100% 사이로 조절할 수 있다. 목록 창은 옮기거나 가장자리를 끌어 크기를 바꾸면 다음에 열 때도 그 자리와 크기로 열린다. 그 자리가 떼어낸 모니터 위라면 지금 화면 가운데로 돌아온다.

## 설치

Xcode 명령줄 도구(Swift 6 이상)만 있으면 된다. Xcode 앱 전체는 필요 없다.

```sh
./scripts/make-app.sh          # build/HoldStack.app 생성
open build/HoldStack.app
```

처음 실행하면 macOS 가 손쉬운 사용(Accessibility) 권한을 묻는다. 다른 앱의 선택 영역을 대신 복사(`⌘C`)하고 붙여넣기(`⌘V`)를 누르려면 이 권한이 필요하다. 권한이 없어도 전역 단축키와 목록 창은 동작하지만, 불러오기는 클립보드에 넣는 데서 멈추므로 `⌘V` 를 직접 눌러야 한다. 붙여넣은 뒤 0.5초가 지나면 원래 복사해 두었던 내용이 이미지나 파일까지 그대로 돌아온다. 그 사이에 새로 복사한 것이 있으면 새것을 남긴다.

앱은 이 컴퓨터에서만 통하는 임시 서명(ad-hoc 서명)을 쓰기 때문에, macOS 는 다시 빌드할 때마다 다른 앱으로 여긴다. 빌드한 뒤에는 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 HoldStack 을 껐다 켠다.

스택은 `~/Library/Application Support/HoldStack/stack.json` 에, 단축키는 `defaults read app.holdstack.HoldStack` 로 볼 수 있는 곳에 저장된다.

## 배포

`build/HoldStack.app` 을 압축해 건네면 된다. 다만 개발자 인증서로 서명하고 Apple 공증(notarization)을 받은 앱이 아니므로, 받은 사람이 처음 열 때 macOS 가 막는다. 받은 사람은 앱을 우클릭해 「열기」를 고르거나, 시스템 설정 → 개인정보 보호 및 보안에서 「그래도 열기」를 누르면 된다. 경고 없이 배포하려면 Apple Developer 계정으로 서명과 공증을 해야 한다.

앱 아이콘은 `scripts/make-icon.swift` 가 코드로 그린다. 고친 뒤 `./scripts/make-icon.sh` 를 돌리면 `Resources/AppIcon.icns` 가 다시 만들어진다.

## 개발

```sh
swift build --product HoldStack   # 앱 빌드
swift run HoldCoreCheck           # 스택과 단축키 설정 로직 검사
```

명령줄 도구에는 XCTest 도 Swift Testing 매크로도 없어서, 검사를 테스트 타깃 대신 별도 실행 파일로 두었다. 실패하면 종료 코드 1 로 끝난다.

코드는 두 덩어리다. `Sources/HoldCore` 는 화면과 상관없는 로직으로, 스택을 저장하고 단축키를 검증한다. `Sources/HoldStack` 은 전역 단축키와 클립보드, 떠 있는 창, 설정 창처럼 OS 와 맞닿는 AppKit 과 SwiftUI 부분이다. 자동 검사는 HoldCore 에만 있고, 키보드와 창 동작은 손으로 확인한다.
